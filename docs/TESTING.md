## 배포

`npm run build`는 외부 패키지 설치 없이 `dist/`를 생성합니다. 상대 경로로 배포되어 하위 경로 호스팅을 지원합니다. GitHub CI에서 검증 후 빌드하며, Pages 배포는 저장소가 Pages 사용을 설정한 경우에만 수행하도록 분리했습니다.
