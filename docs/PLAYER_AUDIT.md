# PL 20개 구단 선수 데이터 전수 점검 · v2

확인 기준일: **2026-11-02**. 공식 PL 현행 선수 명단 601명과 별도 공식 근거가 있는 아카데미 7명, 총 **608명**을 재검토했습니다. 전체 실존 선수 DB는 22,383명입니다.

## 원인과 수정

이전 버전은 FPL의 `can_select`를 현재 소속의 근거로 사용했습니다. 이 항목에는 이적·임대 후에도 남아 있는 선수가 있어 잘못된 소속이 섞였습니다. 능력은 시장 가치의 로그 변환, 잠재력은 나이와 ID 기반 가산으로 정했기 때문에 나이가 많은 주전과 가치 자료가 오래된 선수가 지나치게 낮아지고, 일부 비싼 유망주에게 지나친 현재 능력·잠재력이 부여됐습니다.

v2는 20개 구단의 공식 PL 명단을 대조하고 날짜가 확인된 구단 이적·임대 발표를 우선합니다. 이름·국적·포지션·소속의 사실과 게임용 능력·잠재력 추정치를 분리합니다. 폭넓은 PL 명단 분류가 MF라는 이유로 기존의 정확한 LW 같은 세부 포지션을 CM으로 바꾸지 않습니다.

- 공식 601명 + 확인된 아카데미 7명: 국적 누락 **0명**. 기존 미확인 국적 22건을 채웠습니다.
- 누락된 실존 선수 30명을 새로 추가하고, 기존 DB에 있었지만 잘못된 소속/미확인으로 빠져 있던 선수도 복구했습니다.
- 코폴라·리처즈 등 확인된 이적/임대 6건을 수정했습니다. 아카데미 소속이 확인되는 선수를 단순히 1군 페이지에서 보이지 않는다는 이유로 방출하지 않습니다.
- 608명 전원을 같은 기준으로 평가하고, 그중 328명은 최근 역할과 경력을 개별 검토했습니다. CA는 520건, PA는 557건 변경됐습니다(신규 선수 포함).
- 선수 ID에 따른 PA 임의 가산을 제거했습니다. 유망주는 추정 범위와 평가 근거를 표시합니다.
- 골키퍼·센터백·다른 필드 선수의 성장·쇠퇴·은퇴 시점을 분리했습니다. 베테랑 GK가 일반 공격수와 같은 속도로 노화하지 않습니다.

## 평가 기준

| 현재 능력 | 게임에서의 의미                 |
| --------- | ------------------------------- |
| 90 이상   | 세계 최상위권                   |
| 85~89     | 리그 정상급                     |
| 80~84     | 강한 1군 주전                   |
| 75~79     | PL 주전·중요 로테이션           |
| 70~74     | 성인 로테이션·백업              |
| 60대 이하 | 경험이 적은 유망주·개발 단계 등 |

현재 능력은 공식 1군 역할, 최근 두 시즌(2024/25·2025/26) 출전, 현 시즌 기용, 포지션·경력 및 개별 검토를 반영합니다. 공개 가격은 약한 참고 신호로만 사용합니다. 부상이나 해외 이력 때문에 PL 출전 기록이 적다는 사실을 낮은 실력의 증거로 단정하지 않습니다. 가격의 나이·재판매 프리미엄과 현재 실력은 별도입니다.

PA는 확정된 미래나 외부 기관의 공식 수치가 아닌 게임상의 추정 상한입니다. 나이, 현재 수준, 성인 경기 경험과 공개된 유망주 평가 근거를 사용합니다. Golden Boy 후보라는 사실만으로 특정 점수의 미래가 보장되지는 않습니다. 표시 범위는 평가의 불확실성이며, 선수 ID에 따른 무작위 포텐을 뜻하지 않습니다.

## 기존 커리어 적용

불러오기 시 데이터 v2로 자동 보정합니다. 인적 사항과 평가를 바꾸되 이미 진행한 경기, 득점 사건, 승점, 현금, 거래 내역은 재계산하지 않습니다. 성장분은 이전 기본 능력 대비 차이를 보존합니다.

첫 시즌에는 사용자가 이적·임대·재계약·이적 명단 등록 등으로 바꾸지 않은 선수의 초기 소속 오류도 보정합니다. 이미 거래하거나 계약을 변경한 선수는 보호합니다. 두 번째 시즌 이후는 가상 세계가 진행된 상태이므로 실제 2026년 명단으로 강제로 되돌리지 않습니다. 최신 초기 소속 전체를 그대로 사용하려면 새 커리어를 시작할 수 있습니다.

## 남은 확인 한계

- 일부 신규 아카데미 선수 12명의 생일은 신뢰할 자료가 부족해 미확인으로 남겼습니다. 국적과 실제 소속은 확인했습니다. 실제 나이를 지어내지 않으며, 시뮬레이션용 연령은 별도로 관리합니다.
- 마테오 요제프는 2026/27 현행 1군 명단에서 확인되지 않고 현재 목적지를 확정할 최근 1차 자료가 부족합니다. 과거 마요르카 임대 기사를 현재 임대로 재사용하지 않고 미확인 소속으로 분리해 영입을 막았습니다.
- 이번 감사 범위는 PL 20개 구단입니다. 해외 전체 선수의 이전 평가·소속이 모두 최신으로 재검증됐다는 의미가 아닙니다.
- 능력·잠재력의 모든 판단이 객관적 사실이 된 것은 아닙니다. 공통 척도를 사용하고 근거를 공개한 게임 평가입니다.
