# TOUCHLINE · 터치라인

2026/27 프리미어리그를 배경으로 하는 한국어 구단주 경영 게임입니다. 사용자는 구단주로서 이적, 계약, 감독, 재정과 투자를 결정하고 감독은 전술과 선발을 자동으로 운영합니다.

## 실행

Node.js 20 이상만 필요합니다. npm 패키지 설치가 필요하지 않습니다.

```sh
npm run dev
# http://localhost:3000
npm test
npm run build
```

`dist/`를 정적 호스팅에 업로드하면 배포됩니다. GitHub Actions는 푸시 때마다 검사·테스트·빌드를 실행합니다. GitHub Pages를 추가로 쓰려면 저장소 Settings → Pages → Source를 GitHub Actions로 설정하고 저장소 변수 `ENABLE_GITHUB_PAGES=true`를 추가한 뒤 워크플로를 실행하세요. 모든 경로는 상대 경로여서 GitHub Pages의 `/soccer/` 같은 하위 경로에서도 동작합니다. `index.html`을 파일로 더블클릭하면 브라우저의 ES 모듈/JSON 보안 정책 때문에 실행되지 않습니다. HTTP 서버를 사용하세요.

## 플레이

1. EPL 20개 팀 중 구단을 고릅니다.
2. 홈 결재함, 스쿼드의 선수단/시장/계약/제안함, 감독 시장에서 구단을 운영합니다.
3. 진행 버튼으로 **시즌 준비 → 전반기 → 겨울 이적시장 → 후반기 → 시즌 결산**을 이동합니다. 경기 단계에서 각 팀의 19경기가 자동으로 진행됩니다.
4. 시즌 종료 18~20위만 게임 오버입니다. 적자·목표 실패·감독 경질은 게임을 끝내지 않습니다.
5. 17위 이상이면 다음 시즌으로 계속합니다. 다른 팀은 3개씩 승격·강등합니다.

커리어는 IndexedDB에 자동 저장됩니다. 설정에서 저장 파일 내보내기/불러오기를 지원합니다. 브라우저나 사이트 주소가 달라지면 저장 공간도 다르므로 파일로 옮겨야 합니다. 브라우저 데이터 삭제·시크릿 모드 종료 시에는 저장이 없어질 수 있습니다.

## 데이터

- **22,353명의 실존 선수**. EPL 현재 활동 선수 564명, 세계 주요 31개 국내 리그의 현역 기록을 포함합니다.
- 2026/27 공식 참가팀: 코번트리·입스위치·헐 시티가 승격한 20팀. 2025/26 참가팀을 그대로 사용하지 않습니다.
- EPL 소속: 2026-11-02 FPL 활동 명단과 공식 9월 등록 자료를 대조. 일부 확인 가능한 여름 해외 이적도 보정했습니다.
- 해외 기본 자료: `dcaribou/transfermarkt-datasets`, **2026-07-06 자료, CC0-1.0**. 최신 해외 소속을 모두 보장하지 않습니다.
- 선수 능력·잠재력·시장 가치·급여·계약, 구단 재정·목표, 감독 능력·성향·급여는 **게임 내 추정치**입니다.
- 데이터에 없는 국적과 나이는 `미확인`입니다. 미확인 소속은 자유계약 선수로 처리하지 않습니다.
- 생성 선수·감독은 `가상`으로 표시합니다. 첫해 실제 선수의 인원수를 가상 선수로 부풀리지 않았습니다.
- 공식 엠블럼·사진은 사용하지 않고 자체 제작 문자 구단 식별자를 사용합니다.

전체 출처와 한계는 [docs/DATA.md](docs/DATA.md), [data/meta.json](data/meta.json)에 있습니다.

## 구현

- 순수 ES 모듈 JavaScript. 화면, 게임 엔진, 저장, JSON 데이터를 분리했습니다. 런타임 API 키와 외부 경기 API가 필요하지 않습니다.
- 380개 고유 대진, 각 구단 홈 19/원정 19, 승점·득실차·다득점 순위표.
- 포지션 적합도·감독·전술·컨디션·사기·부상·홈 이점과 Poisson 득점 모델. 선발 및 교체 출전 시간, 득점·도움 사건이 일치합니다.
- 선수 상세/필터/페이지 검색, 최대 3회 이적 협상, 급여/이적료·구단 격차·판매 의사 반영. 제안 수락/거절, 판매, 임대, 재계약, 계약 해지와 만료.
- 다른 EPL 구단도 예산과 선수단 깊이에 따라 이적·판매·재계약·감독 교체를 진행합니다.
- 감독 선임·경질·재계약·타 구단 감독 영입, 보상금과 전술 적응 비용.
- 누적 현금, 별도 이적 한도, 주급 한도, 시즌 수익·지출, 적자 이자, 팬, 목표, 시설 투자, 조건별 구단주 사건.
- 나이·성장·쇠퇴·은퇴·가상 유망주·승강·시즌별 순위/이적/감독/재정/주요 선수 기록.
- 브라우저 자동 저장·수동 저장·JSON 백업·가져오기. 저장 파일의 경기·선수 무결성을 검증합니다.

## 현재 범위와 한계

- EPL 리그만 경기 시뮬레이션합니다. 유럽대항전 진출권은 후원 보너스로 반영하며 컵대회·유럽대항전 경기를 별도로 생성하지 않습니다.
- 해외 리그의 경기·세부 재정은 계산하지 않으며 계약 갱신과 유망주 생성으로 이적시장 풀이 유지됩니다.
- 잉글랜드 2부 전체 경기를 계산하지 않습니다. 실제 구단 승격 후보의 전력과 확률로 3팀을 승격시키는 캐주얼 모델입니다. 승격 구단의 선수 부족분은 명확히 표시된 가상 유망주로 보충합니다.
- 처음부터 현재 선수 명단을 사용하는 대체 시작 세계입니다. 실제 개막 이전 명단이나 실제 시즌 경기 결과를 재현하지 않습니다.
- 전 세계 모든 리그/등록 선수를 완전히 포함하지 않습니다. 공개 자료에 잡힌 현역 기록 중심이며, 해외 여름 이적·계약은 일부 오래되었거나 미확인입니다.
- 능력은 공개 가치 자료에 기초한 일관된 게임 추정이며, 정밀한 전문 스카우팅 평가가 아닙니다. 실제 계약 기간·금액을 주장하지 않습니다.
- 세이브는 1슬롯입니다. 다른 커리어를 만들기 전에 파일로 백업하세요. 서버 간 동기화/멀티플레이는 없습니다.
- 장기 세계는 20시즌 테스트했습니다. 무한 플레이를 허용하지만 무한 기간의 실제 검증을 뜻하지 않습니다.

## 검증

`npm test`는 Node 내장 테스트만 사용합니다. [docs/TESTING.md](docs/TESTING.md)에 자동·브라우저 검증 범위가 있습니다.

scripts/           정적 빌드, 개발 서버, 데이터 가져오기
